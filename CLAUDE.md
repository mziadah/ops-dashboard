# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

- Spring Boot 3.2 / Java 17 read-only JSON API under `/api` (plain SQL via Spring JDBC, Flyway, no JPA) + vanilla JS/CSS frontend in `src/main/resources/static/` (no framework, no build step).
- Run: `docker compose up -d db && ./mvnw spring-boot:run` (http://localhost:8080); no Docker: `SPRING_PROFILES_ACTIVE=demo ./mvnw spring-boot:run` (H2).
- Test: `./mvnw test` (25, H2) and `npm test` (45, Jest + jsdom). One test: `./mvnw test -Dtest=Class#method`, `npx jest path -t "name"`.
- "Today" is pinned to 2026-09-21 (`ClockConfig`, `ops.today`); always inject `Clock`, never read the machine date.
- Controllers → `DateRange.resolve` → repositories (SQL must run on both PostgreSQL and H2) → records as JSON.
- `app.js` exposes `initApp(document, fetchImpl)`; Jest drives it through `src/test/javascript/setup/loadApp.js`, which fakes every `/api` endpoint.
- Every new element id in `index.html` must be added to `REGISTERED_IDS` in `loadApp.js` (`harness.test.js` enforces it).
- Seed data is generated by `tools/make_seed.py`; never edit an applied Flyway migration.
- Tickets are in `docs/tickets/`; the ticket file wins over chat. Done = both suites green with counts reported, app restarted.
- pom.xml dependencies are frozen. Any change needs a CHG ticket.
